# Grustic

Grustic is a proposed modular graph foundation for Rust. Applications compose
its graph model, query frontend, semantic analysis, optimizer and execution
adapters. Nutmeg will use it to provide graph operations on Sail; Cosmolang
will expose bounded graph exploration to browsers and agents.

**Status: Wave 4 design review.** This repository currently contains proposals
and source-review records. It has no Rust implementation or released API.

Start with [the Wave 4 plan](docs/design/00-wave4-plan.md).
